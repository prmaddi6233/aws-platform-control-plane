# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email: **maddipradeep201@gmail.com**

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

I will acknowledge receipt within 48 hours and provide an estimated timeline for
a fix.

## Scope

This repository is a reference architecture using synthetic data. It does not
process real customer data or connect to production AWS accounts.

Security reports are still welcome — the patterns demonstrated here are intended
for adaptation into production environments, and correctness matters.

## Supported Versions

Only the latest commit on `main` is actively maintained.
